# 🎓 FIAP Cyber Defense — Study Notes

Personal study notes from my two-year undergraduate program in **Cyber Defense** (Cybersecurity Technologist) at FIAP, Brazil.
Each phase has a summary written in my own words, the tools and commands practised, review questions,
and how the topic connects to real SOC / blue-team work.

> Summaries are in **Portuguese** with technical terms in **English**. The glossary is fully bilingual (PT ↔ EN).
